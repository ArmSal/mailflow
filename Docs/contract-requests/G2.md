# G2 contract request

`IDocumentStore.MoveAsync(storedPath, newCategorySubfolder, ct)` returns `Task` (void). On a name collision the
file is renamed ("name (2).pdf"), so the caller cannot learn the new path to update `Document.StoredPath`.
Request: return `Task<string>` (the new full path). Workaround: the store returns nothing; the caller must
recompute the path or avoid collisions.
