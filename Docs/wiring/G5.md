# G5 wiring (Stores / Mailboxes / Printers / Categories / Rules pages)

Nothing is registered by G5. The integrator must add to Program.cs / DI:

| Service | Used by | Notes |
|---|---|---|
| `IAppDbContext` | all PageModels | scoped, EF Core context |
| `ISecretStore` | Mailboxes/Edit | `Protect` on save, `Unprotect` only for "Tester la connexion" with a blank password field |
| `IMailClient` | Mailboxes/Edit | `TestConnectionAsync` |
| `IPrinterService` | Printers/Index, Printers/Edit | `GetInstalledPrinters`, `PrintAsync` |
| `Mailflow.Web.Pages.Printers.ITestPageProvider` | Printers/Index | `string GetTestPagePath()` returning a PDF path (e.g. a bundled test page) |
| `Mailflow.Web.Pages.Rules.IRuleTester` | Rules/Edit | `Task<IReadOnlyList<RuleTestMatch>> TestAsync(int ruleId, int lastEmails, CancellationToken)`; must be read-only (no save/print/move/mark) and evaluate the saved rule against the last N emails (e.g. via `IMailClient.FetchSinceAsync` or ProcessedMessages) |

Also required: `AddRazorPages()`, antiforgery (default), `htmx.min.js` loaded in the layout (owned by the layout agent), and the layout `Scripts` section (Mailboxes/Edit and Printers/Edit use `@section Scripts`).

Menu links to add (layout agent): `/Stores`, `/Mailboxes`, `/Printers`, `/Categories`, `/Rules`, `/Rules/AllowedSenders`.

DbContext model requirement: `Setting` needs `HasKey(s => s.Key)`.
